## Notes

- All 11 repos are read-only against Nansen; none execute trades or onchain transactions in their shipped/public paths. nansen-undertaker has dormant trade_quote/prepare/execute client functions but explicitly blocks/excludes the execute path from the public repo and demo.
- nansen-muse-connector is the outlier: zero source code, pure MCP-connector documentation pointing at Nansen's own hosted server, with admittedly fabricated example outputs. Not a functioning submission as reviewed.
- Exit/sell-side coverage ranges from none (vampnet, fresh-token-radar, otg-nansen, pulsefeed-ledger, nymis) to genuine sell-volume/acceleration-based exit signals (smart-money-flows-tracker) to sell-volume-as-evidence (chaincheck, singulant-proof, undertaker).
- Strongest data-integration + functionality + docs combination: dvntekim/vampnet (9), CoolCriSyS/fresh-token-radar (8), RenatMursalimov/nansen-undertaker (8), TheSingulant/singulant-proof (8), Ibrahimjibril/chaincheck (8).
- Weakest: CoolCriSyS/nansen-muse-connector (3, no code), aasunbul/nansen-thesis-court (4, 1 commit, hardcoded Windows paths in the only data-refresh script, missing `key_pool` module).
- All findings sourced via `gh repo view`, `gh api .../git/trees/HEAD?recursive=1`, `gh api .../contents/...`, and `gh api .../commits`, run by parallel subagents per repo; no browser used.
