## Notes

- All 14 repos exist and returned real content via `gh api`; none private/empty/missing.
- Only two repos execute real money-moving actions outside their own toy economy: **DProC-debug/CryptoTradingAgent** (real Hyperliquid perp open/close, paper mode by default) and **RaYYeR220/whale-street** (Mirror feature signs real capped Hyperliquid orders, disabled in public demo). **Iziedking/nock-app** executes an onchain guard-contract `exit()` call and sends Telegram alerts, plus claims a settled x402/USDC payment. **memeshee/nansen-league** sends real Telegram messages (no funds/onchain).
- Exit/sell-side coverage is broad but shallow: most entries consume sell/distribution data as one input to a score, veto, or backtest condition (parallax, time-machine, whichone, swenai-nansen, nansen-league, crucible, hindsight, bait's inverse-framing). Only **nock-app** and **whale-street** tie sell/exit detection to an actual triggered action (a guard-contract exit, or a filing event on-screen). None ship a dedicated proactive "smart money is exiting now, alert me" product as its primary feature.
- Strongest data-integration + functionality + docs combination: RaYYeR220/whale-street (9, 14 endpoints, 153 commits, real execution + exit detection), wolfgang-aura/bait (9, no-network verify suite reproduces every claim), DProC-debug/CryptoTradingAgent (9, real trades + hard confidence override on Nansen conflict), edycutjong/whichone (9, cleanest falsifiable logic, 149 tests).
- Weakest: jadenlee7/coineasy-onchain-brief (5, shipped default demo makes zero live Nansen calls), bykaralord25/nansen-time-machine (6, live app calls no Nansen API at runtime — fully pre-baked).
- Docs/code mismatches worth flagging to judges (not fabrication, both otherwise honest about limits): josephlacsamana/swenai-nansen and memeshee/nansen-league each claim one README endpoint not found in callable code.
- Repo-history flag: Iziedking/nock-app has a single commit with createdAt/pushedAt seconds apart — a snapshot push rather than iterative public development; code itself (contracts, worker, tests) looks substantial and real.
- Unverified across all 14: no app was executed live (no Nansen key, no browser/curl on live services per task scope) — all findings are from `gh api` source/README reading, not independent runtime verification. Findings sourced via `gh repo view`, `gh api .../git/trees/HEAD?recursive=1`, `gh api .../contents/...`, `gh api .../commits`, run by parallel subagents per repo group.
